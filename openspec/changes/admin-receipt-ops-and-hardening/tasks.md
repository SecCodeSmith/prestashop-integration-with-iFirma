# Tasks

Conventions for every task:
- Keep PHP 7.2-compatible syntax (`array()`, no typed properties) and the module licence header on every new or touched `.php`, `.tpl`, `.js` and `.css` file; `python tools/check_license_headers.py` must pass.
- Run `php -l` on every edited PHP file and the PHPUnit suite (in the 8.1 container: `docker compose exec -T -u www-data prestashop sh -c "cd modules/ifirma && php tests/vendor/bin/phpunit -c phpunit.xml.dist"`) after each group.
- Every new `l()` string goes into `tools/pl_translations_map.php` and `translations/pl.php` is regenerated with `php tools/generate_pl_translations.php` in the same task; `tests/Unit/TranslationCoverageTest.php` enforces it. Words the scripts need are passed through `Media::addJsDef` from `ifirma.php`, never written in the `.js` files.
- Run `graphify update .` after code changes (CLAUDE.md), alone from the repo root.

Design decisions are referenced as D1–D15 (design.md); scenarios by name from the delta specs of this change (`specs/<capability>/spec.md`).
