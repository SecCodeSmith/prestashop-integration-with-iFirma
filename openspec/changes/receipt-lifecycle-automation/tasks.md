# Tasks

Conventions for every task: keep PHP 7.2-compatible syntax (`array()`, no typed properties), add the module license header to every new `.php`/`.tpl`/`.css`/`.js` file (`python tools/check_license_headers.py` must pass), run `git ls-files '*.php' | xargs -n1 php -l` after PHP edits, and run `graphify update .` after code changes (project convention in CLAUDE.md). `test-stack/` is a separate git repository: commit its changes there.
