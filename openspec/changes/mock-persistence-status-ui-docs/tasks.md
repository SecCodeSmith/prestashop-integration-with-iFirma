# Tasks

Conventions for every task:
- Groups 1-3 change the `test-stack` submodule (its own public MIT repository): commit there first and push before the pointer is bumped here (group 7). Every new `.py` file carries the mock's MIT header; `python test-stack/tools/check_license_headers.py` must pass.
- The mock's pytest suite (`cd test-stack/ifirma-mock && python -m pytest`) must pass after every group that touches the mock; the existing tests must pass unchanged (they prove the JSON contract is intact).
- Groups 4-6 change only documentation and `tools/` in this repository: no PHP, SQL, template or translation edits, so no PHPUnit or translation work is owed; `npm run verify:package` must still pass.
- Run `graphify update .` after the code changes land (CLAUDE.md), and `graphify query` before grepping when exploring the module for the architecture page.
- Work is split for parallel agents as in design D8: groups 1, 3, 4, 5 can start together; group 2 with or right after group 1 (disjoint regions of `main.py`); group 6 after groups 1-3 run on the PS 8.1 stack; group 7 is the lead's integration. Variable names, routes and image file names are fixed in design D1-D6 and must be used as written.

Design decisions are referenced as D1-D8 (design.md); scenarios by name from `specs/mock-state-persistence/spec.md` and `specs/mock-status-page/spec.md`.
