# Tasks

Conventions for every task: keep PHP 7.2-compatible syntax (`array()`, no typed properties), keep the module license header on every touched `.php`/`.tpl` file (`python tools/check_license_headers.py` must pass), run `php -l` on every edited PHP file, run the PHPUnit suite (`vendor/bin/phpunit`) after each group, and run `graphify update .` after code changes (project convention in CLAUDE.md). Every new `l()` string goes into `tools/pl_translations_map.php` and `translations/pl.php` is regenerated with `php tools/generate_pl_translations.php` in the same task (`tests/Unit/TranslationCoverageTest.php` enforces it). `test-stack/` is a separate git repository: commit its changes there. Design decisions are referenced as D1-D6 (design.md); scenarios by name from the two delta specs.
