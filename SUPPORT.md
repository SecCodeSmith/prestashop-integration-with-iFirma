# Getting support

## Where to ask

* **Questions and bugs:** open a GitHub
  [issue](https://github.com/SecCodeSmith/prestashop-integration-with-iFirma/issues)
  for a reproducible bug, or a
  [discussion](https://github.com/SecCodeSmith/prestashop-integration-with-iFirma/discussions)
  for a question about usage or configuration. Use the issue forms, and never
  paste API keys, tokens or customer data.
* **Documentation:** read the pages in [`docs/`](docs/) first:
  * [`docs/usage.md`](docs/usage.md): how the module is used day to day
  * [`docs/configuration.md`](docs/configuration.md): settings and their meaning
  * [`docs/troubleshooting.md`](docs/troubleshooting.md): common problems and fixes
  * [`docs/upgrading.md`](docs/upgrading.md): upgrade steps between versions
* **Security issues:** do not use issues or discussions. Follow
  [SECURITY.md](SECURITY.md).

## What is supported

* PrestaShop **8.0 to 9.x**
* PHP **7.2 to 8.x**

Versions outside these ranges are not supported. For PrestaShop 1.7, use the
1.1.x line of the module.

## Commercial support

Enterprise licensees under the [SecCodeSmith Commercial License](LICENCE) receive
commercial support by e-mail at <admin@seccodesmith.pl>. Include your licence
details, the module version, the PrestaShop and PHP versions, and a clear
description of the problem. Do not include API keys, tokens or customer data in
e-mails.

Support for the community is best effort and carries no response time commitment.
